# Üçüncü taraf varlıklar

- **Sharp** — yalnız derleme sırasında AVIF/WebP/PNG üretimi; ZIP çalışma zamanında bağımlılık değildir.
- **Liberation Sans** — yerel Regular ve Bold font dosyaları; PDF.js paketindeki font varlıklarından alınmıştır.
- **Open-Meteo** — kullanıcı isteğiyle güncel hava ve coğrafi eşleme verisi; API anahtarı gerektirmez.
- **Bootstrap** — dağıtımda tüm kütüphane yerine kullanılan container/row/column sınıflarını kapsayan yerel, uyumlu grid alt kümesi bulunur.

jQuery, Font Awesome, CDN veya çalışma zamanında paket yöneticisi kullanılmaz.
