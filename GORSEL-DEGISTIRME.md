# Görsel Değiştirme Rehberi

Ana sayfadaki örnek görseller aşağıdaki klasördedir:

`assets/images/showcase/`

Aynı dosya adını koruyarak kendi görsellerinizi yüklediğinizde kod değiştirmeniz gerekmez.

| Dosya | Kullanım | Önerilen oran |
|---|---|---|
| `hero-banner.webp` | Ana sayfa büyük görsel | 16:9 veya 21:9 |
| `web-showcase.webp` | Web tasarım çözümü | 4:3 |
| `ecommerce.webp` | E-ticaret çözümü | 4:3 |
| `brand-identity.webp` | Logo ve kurumsal kimlik | 4:3 |
| `final-office.webp` | Kurumsal çalışma alanı | 16:9 |

## Görsel kuralları

- WebP veya AVIF kullanın.
- Hero görselini yaklaşık 250–400 KB altında tutun.
- Diğer görselleri yaklaşık 100–250 KB aralığında tutun.
- Görselleri internetten izinsiz kopyalamayın.
- Dosya adlarını açıklayıcı kullanın.
- Alt metni görselin gerçek içeriğini tarif edecek şekilde güncelleyin.
