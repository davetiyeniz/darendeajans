# Darende Ajans — GitHub Pages yayını

Bu klasörün üretim çıktısı, ana dizininde `index.html` bulunan statik web sitesidir. Dosyalar GitHub deposunun köküne yüklendiğinde GitHub Pages üzerinden yayınlanabilir.

## Yayınlama

1. Final ZIP’i açın.
2. ZIP içindeki tüm dosya ve klasörleri GitHub deposunun ana dizinine yükleyin.
3. GitHub’da **Settings → Pages** bölümünde yayın kaynağı olarak ana dalın kökünü seçin.
4. Özel alan adı için paketteki `CNAME` dosyasını koruyun.

## İçerik yapısı

- `index.html`: ana sayfa
- `hizmetler/`: hizmet sayfaları
- `ajans/`: ajans sayfası
- `iletisim/`: telefon, WhatsApp ve teklif alanı
- `darende-rehberi/` ve `yoresel-urunler/`: yerel arama niyetine yönelik içerikler
- `assets/`: stil, JavaScript, logo, görsel ve motion dosyaları
- `robots.txt`, `sitemap.xml`, `CNAME`, `404.html`: teknik yayın ve SEO dosyaları
